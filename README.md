# CU Boulder APPM Directed Reading Program — Spring 2027

This is a **complete, standalone Jekyll Academic Pages site** based directly on the uploaded source of `grahammauer.github.io` (October 20, 2026 snapshot). It uses the original `_layouts`, `_includes`, `_sass`, `assets/js`, and theme settings of that repository. No external template download or installer is needed.

## Pages

- `/` — short overview and application dates
- `/projects/` — all eight proposed projects, fully expanded (no cards, accordions, or filters)
- `/apply/` — student application details and FAQ

## Local preview on macOS

Use Ruby 3.3, as with the personal site:

```bash
export PATH="$(brew --prefix ruby@3.3)/bin:$PATH"
ruby -v
bundle install
bundle exec jekyll serve -l -H localhost
```

Visit `http://localhost:4000`. **Use Jekyll, not `python3 -m http.server`**, to generate the layout and CSS from Sass and Liquid templates.

## Publish to GitHub Pages

For a clean replacement of the previously generated Minima site, open Terminal in **this extracted folder** and run:

```bash
bash install_into_repo.sh ~/Documents/cuboulderdrp.github.io
```

The script saves a full timestamped backup next to the repository, replaces existing site files with **all** the Academic Pages theme files, and preserves `.git`. No template download is needed. Check the target directory carefully before invoking it.

Alternatively, manually delete old site files (except `.git`) and copy the **contents** of this folder to your existing repository.

Then commit and push to your repository's default branch, and in GitHub `Settings → Pages`, choose **Deploy from a branch** with that branch and the root folder. The supplied `_config.yml` assumes `https://cuboulderdrp.github.io`.

If the account/repository differs, change `url` and `repository` in `_config.yml`.

## Edits

- Add the real undergraduate application form URL to `_data/drp.yml` (`application_url`). No application link is invented.
- Edit mentor bios and full project statements in `_data/projects.json`. The entire projects list updates automatically.
- Edit homepage or Apply/FAQ content in `_pages/about.md` and `_pages/apply.md`.
- Edit gold-accent CSS in `_sass/_drp.scss`. The **original stylesheet** `assets/css/main.scss` imports it as part of the full Academic Pages design; this is what makes the site look like the personal site.
- Header navigation: `_data/navigation.yml`.

The `_site/` directory is auto-generated by Jekyll and is not included in the ZIP.

**Important:** `_includes/base_path` was adjusted to root-relative paths, since the original personal site derives asset URLs from the production domain. With this change, the CSS and navigation work on `localhost:4000` *before* the site is published. Keep this file as supplied.
